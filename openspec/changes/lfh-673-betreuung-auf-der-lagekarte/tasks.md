# Tasks

Jede Aufgabe entsteht test-first (`superpowers:test-driven-development`). Zuerst kommt der
rote Test, dann der Code. Die Arbeit hat **zwei Hälften, die sich einzeln liefern
lassen**. Die Gruppen 1–3 bringen den Stellen-Marker und brauchen keinen Rebuild, die
Gruppen 4–6 bringen die Bezirksfläche. Gruppe 7 schließt beide ab.
