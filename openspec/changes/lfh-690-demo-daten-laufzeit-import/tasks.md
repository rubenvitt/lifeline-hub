Test, dann der Code. Rust-Gates je Aufgabe gescopt (`cargo test --test …`, `--lib …`), die
volle Suite erst in 7.x. Frontend-Aufgaben fahren die volle Vitest-Suite, weil Guards sonst
durchrutschen. Jeder `_tx`-Split ist ein eigener Commit.
