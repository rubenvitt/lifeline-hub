# Sicherheitslücken melden

Bitte melde eine Sicherheitslücke **nicht** als öffentliches Issue.

Nutze stattdessen die private Meldung von GitHub:
[Sicherheitslücke melden](https://github.com/rubenvitt/lifeline-hub/security/advisories/new)
(Reiter „Security“ → „Report a vulnerability“). Die Meldung sieht nur die Entwicklung.

Ohne GitHub-Konto geht die Meldung an rueckmeldung@lifeline-hub.de, Betreff beginnend mit
„Sicherheit:“.

Hilfreich sind die Version (Benutzermenü), betroffene Oberfläche (Browser, Desktop-App,
gekoppeltes Gerät) und die Schritte zum Nachstellen. Keine echten Einsatz- oder Personendaten
mitschicken.

Gemeldet wird gegen den jeweils neuesten Stand eines Kanals (Alpha, Beta, Stabil); ältere
Versionen bekommen keine eigenen Korrekturen.
