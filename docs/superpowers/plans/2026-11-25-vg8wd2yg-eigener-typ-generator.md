# Eigener Typ-Generator Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** `types.generated.ts` entsteht aus einem eigenen Node-Skript statt aus openapi-typescript, byte-gleich bis auf die Kopfzeile.

**Architecture:** Reines ES-Modul `frontend/scripts/gen-types.mjs` mit einer exportierten Funktion
`generateTypes(doc)` und einer CLI-Hülle; Typen für die Tests in `gen-types.d.mts` (Muster wie
`changelog-zerlegen.mjs`). Die heutige Datei ist das Orakel.

**Tech Stack:** Node (mise), Vitest, pnpm.

**Spec:** `docs/superpowers/specs/2026-11-25-vg8wd2yg-eigener-typ-generator-design.md`

## Global Constraints

- Nur `node:`-Module, keine npm-Abhängigkeit.
- Kopfzeile: `This file was auto-generated by frontend/scripts/gen-types.mjs.`; „Do not make direct changes to the file.“ bleibt.
- `gen:types` = `node scripts/gen-types.mjs src/api/openapi.json -o src/api/types.generated.ts`.
- Unbekannter Schlüssel oder unbekannte `type`-Form → Fehler mit Schemaname und JSON-Pfad, Exit ≠ 0.
- Kommentare und Commit-Texte deutsch, Bezeichner englisch (`AGENTS.md`, Bezeichner-Sprache).

## Review Focus

- Mehrzeilige `description` mit Sonderzeichen (`*/`, Backticks, Anführungszeichen) → gleiche Escapes wie heute.
- Feldnamen, die keine JS-Bezeichner sind (Bindestrich, Ziffer vorn) → in Anführungszeichen wie heute.
- `enum` mit `null` oder Zahlen → gleiche Literal-Schreibweise wie heute.
- `oneOf` aus Objekten mit `description` je Variante → Kommentare an derselben Stelle wie heute.
- Neue utoipa-Form (z. B. `const`, `anyOf`) → lauter Abbruch statt `unknown`.

Abgedeckt durch den Byte-Vergleich in Task 1 (Fälle 1–4) und den Abbruchtest (Fall 5).
